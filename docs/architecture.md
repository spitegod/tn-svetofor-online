# Архитектура

Проект — модульный монолит: один Go backend, один Vue frontend и PostgreSQL. Парсер `nav.tn.ru` является общей частью сервиса и не принадлежит отдельному распоряжению.

## Backend

```text
backend/
├── cmd/server/                 # точка входа
└── internal/
    ├── app/                    # сборка зависимостей и жизненный цикл
    ├── apperror/               # типизированные прикладные ошибки
    ├── config/                 # конфигурация из окружения
    ├── db/                     # PostgreSQL и версионированные миграции
    ├── delivery/http/          # HTTP-маршруты и контракты
    ├── model/                  # структуры предметной области и DTO
    ├── repository/             # SQL и транзакции
    └── service/                # правила, XLSX, экспорт и парсер
```

Сервисы зависят от узких интерфейсов репозиториев. Транзакции принадлежат repository-слою; составной импорт распоряжения выполняется одной транзакцией. Миграции выполняются последовательно под PostgreSQL advisory lock и фиксируются в `schema_migrations`.

Ручной запуск парсера создаёт фоновую задачу и сразу возвращает HTTP `202`. Автоматический запуск выполняется планировщиком. Одновременные запуски в одном процессе и между несколькими экземплярами backend блокируются mutex и PostgreSQL advisory lock соответственно.

Импорт XLSX не делает сетевых запросов к `nav.tn.ru`. Ссылки и типы строительства при чтении классификации объединяются с общими данными `nav_systems` и `nav_system_characteristics`, поэтому новый успешный запуск парсера обогащает все распоряжения.

## Frontend

```text
frontend/src/
├── app/
│   ├── App.vue                 # composition root и координация общего состояния
│   └── providers/              # глобальные стили
├── pages/                       # отдельные представления пяти разделов
├── features/
│   ├── nav-parser/             # UI, состояние и API сценариев парсера
│   └── system-history/         # модальное окно истории системы
├── widgets/                     # шапка и общий подвал страниц
└── shared/
    ├── api/                    # API-клиент и типы контрактов
    ├── assets/                 # изображения и логотипы
    ├── lib/                    # переиспользуемая логика
    └── ui/                     # общие Vue-компоненты
```

Навигация использует hash-маршруты с поддержкой истории браузера. Долгие запросы списков отменяются через `AbortController`; отложенные сохранения строк также отменяют устаревший запрос. Настройки интерфейса хранятся через общий модуль preferences.

`App.vue` больше не содержит разметку отдельных страниц: он выбирает page-view и связывает их с общим состоянием. Самостоятельные сценарии со своим жизненным циклом, такие как парсер, размещаются в `features` и инкапсулируют API-вызовы в composable. Независимые элементы каркаса находятся в `widgets`, а не привязанные к предметной области контракты и UI — в `shared`.
